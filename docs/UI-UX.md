# Material 3 UI/UX Design Guide

## Design Tokens (Seed Color: #1A73E8 - Security Blue)
- **Primary:** `#1A73E8`
- **On-Primary:** `#FFFFFF`
- **Primary-Container:** `#D3E3FD`
- **Error:** `#B3261E` (For critical alerts)
- **Surface:** `#F8F9FA` (Light) / `#121212` (Dark)

## Typography (Roboto / Inter)
- **Display:** For critical system status.
- **Headline/Title:** Dashboard cards.
- **Body:** Audit log entries.

## Severity Mapping
- **Critical:** `#B3261E` (Red)
- **High:** `#F29900` (Orange)
- **Medium:** `#FABB05` (Yellow)
- **Low/Info:** `#1A73E8` (Blue)

## Dashboard Components
- **Top App Bar:** Current VM/Host status.
- **Navigation Rail:** Switch between Events, Rules, Settings.
- **Data Table:** Display `auid`, `comm`, `path` with clear contrast.
- **Empty State:** "No recent incidents" illustration.

*Ensure all touch targets are at least 48dp.*
